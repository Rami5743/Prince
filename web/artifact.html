Prince of Persia, Reconstructed

The 1990 DOS game, rebuilt to run here — reading the original's own data files and the tables inside its executable.

Press any key to begin. Arrow keys or the numeric keypad to move — a corner key jumps that way, as it does in the original. Shift steps carefully and takes hold of a ledge; up while running is a running jump. After a fall, any key begins the level again.

The rest of the original's keys are here too. Space shows the time left, Esc pauses, Ctrl+A begins the level again, Ctrl+R goes back to the title, Ctrl+S turns the sound off and on, and Shift+L skips a level, which the original allows up to level 4. Type megahit for the cheats, as the original takes it on its command line: then R raises a fallen Prince, K fells the guard, Shift+T and Shift+S give a flask and a hit point, Shift+W is the feather, Shift+I turns the screen over, Shift+B puts the lights out, + and − move the clock, and H J U N look at the rooms around this one, with Ctrl+B to come back.

The whole game is here, from the title screen through all fourteen levels. Every room has been compared against the real game running under emulation, and matches it pixel for pixel.
